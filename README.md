# Console Java Game

This is a console-based game written in Java.

My main goal for this project was to practice:
- object-oriented programming
- game logic and flow
- clean structure of a larger program

---

## Game idea
The player moves around a grid field and collect transistors.
Each move cost turns(if there is turns<0 and player didn't collect enough transistors -> player lost).Player wins in case if he collect all required transistors in given turns.

---

## How the game works

- The game is played in the command line interface.
- The player is @.
- Enemies are %.
- Empty cells are .
- Numbers are flowers that contain transistors.

---

### Player controls
- `w` – move up
- `s` – move down
- `a` – move left
- `d` – move right
